## 💡 DICAS DE OURO

1. **Não tente reescrever tudo**
   - Copie e adapte (50% mais rápido)
   - Preservar estrutura
   - Adicione seu contexto

2. **Insira diagramas cedo**
   - Não deixe para o final
   - Ajudam a organizar pensamento
   - Vale mais que texto

3. **Use exemplos reais**
   - JSON real (não inventado)
   - Casos de erro verdadeiros
   - Dados de benchmark reais

4. **Explique o "porquê"**
   - "Usamos X porque Y"
   - Não apenas "Usamos X"
   - Todo parágrafo técnico precisa justificação

5. **Seja honesto sobre limitações**
   - LLM alucinations? Mencione
   - Escalabilidade limitada? Transparente
   - Erros humanos mais confiáveis? Admita
   - Limitações ≠ Mau projeto (= profissionalismo)
